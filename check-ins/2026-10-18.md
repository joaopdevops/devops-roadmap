## 🇬🇧 English

**Planning a cluster's IP addresses — where subnetting meets HCI**

Before a Nutanix cluster is deployed, every address must be planned: the installer writes them into each node, and re-addressing a live cluster is painful.

| Scope | IP | Purpose |
|---|---|---|
| Per node | **Hypervisor (AHV)** | the host that runs the VMs |
| Per node | **CVM** | the storage controller on that node |
| Per node | **IPMI** | **out-of-band management** — reach the hardware even when the OS is down |
| Per cluster | **Virtual IP** | single admin entry point to Prism, follows the leader CVM |
| Per cluster | **Data Services IP** | client access to Volumes/Files, survives a CVM failure |

**Formula:** `nodes × 3 + 2`. A 3-node cluster → **11 IPs** ✅.
Hypervisor, CVM and both cluster IPs share the **management subnet** (plus the gateway); IPMI usually sits on a separate network.

Check question passed: *"the hypervisor hung — which IP do you use to power-cycle the node?"* → **IPMI**, because it's on its own network.

## 🇧🇷 Português

**Planejando os IPs de um cluster — onde subnetting encontra HCI**

Antes do deploy de um cluster Nutanix, todo endereço precisa estar planejado: o instalador grava cada um nos nodes, e trocar IP de cluster no ar é trabalhoso.

| Escopo | IP | Função |
|---|---|---|
| Por node | **Hypervisor (AHV)** | o host que roda as VMs |
| Por node | **CVM** | o controlador de storage daquele node |
| Por node | **IPMI** | **gerência out-of-band** — acessa o hardware mesmo com o sistema fora |
| Por cluster | **Virtual IP** | entrada única de administração no Prism |
| Por cluster | **Data Services IP** | acesso dos clientes a Volumes/Files |

**Fórmula:** `nodes × 3 + 2`. Cluster de 3 nodes → **11 IPs** ✅. Hypervisor, CVM e os dois IPs de cluster ficam na **sub-rede de gerência** (mais o gateway); o IPMI costuma ficar numa rede separada.
