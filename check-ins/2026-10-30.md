## 🇬🇧 English

**Objective 1.1 closed — how many IPs a Nutanix cluster needs**

| Scope | IP | Purpose |
|---|---|---|
| Per node | **IPMI** | out-of-band remote management — works even when the server is powered off |
| Per node | **AHV** (host) | the hypervisor — runs the VMs |
| Per node | **CVM** | Controller VM — manages the node's storage |
| Per cluster | **Cluster VIP** | opens Prism Element in the browser; floats to another CVM if the owner fails |
| Per cluster | **Data Services IP** | external block storage access (iSCSI) |

Formula: **nodes × 3 + 2** → 3 nodes = 11 IPs · 4 nodes = **14** ✅ (calculated live).

Recurring mistake: "the CVM manages the VMs" ❌ (missed on Day 55 and Day 56). Fixed: **AHV runs the VMs, the CVM handles storage, Prism manages**. On Day 57 the CVM came out right on the first try, in Portuguese and in English.

English fixes from the teach-back: *responsible **for*** (not *by*), *two more IPs*, *its function is to run*.

**Why it matters for DevOps:** an IP plan is the first thing that breaks a deployment; separating management (IPMI), compute (hypervisor) and storage (CVM) addresses is the same discipline as separating planes in any network.
