**Micro-lab — watching the route decision live with `ip route get`**
- Instead of reading theory, I asked my own Linux kernel to decide, live:

```
ip route get 192.168.0.50  →  ... dev wlp0s20f3            (no via — neighbor, direct delivery)
ip route get 8.8.8.8       →  8.8.8.8 via 192.168.0.1 ...  (via — hand it to the gateway)
```

- **Key insight nailed down:** every line in the routing table is a *known* route. The question each line answers is not "do I know it?" but "**how do I deliver?**" — no `via` = connected route, deliver directly; with `via` = deliver *through* the gateway (middleman).

**New mechanic learned — prefix matching (reading the IF of a route)**
- Each route line is an **IF → THEN** rule. The number after the slash says how many leading octets are locked: `/8` = "starts with 10.", `/16` = "starts with 172.16.", `/24` = "starts with 192.168.0.", `/0` = anything (the default).
- To test a match, compare only the locked octets: `8.8.8.8` vs `10.0.0.0/8` → 8 ≠ 10 → no match.
- **Longest prefix match now makes literal sense:** more locked octets = more specific = wins. The default `/0` locks nothing — last resort.
- **No matching line and no default?** The router does not guess: it drops the packet and returns **ICMP Destination Unreachable**. The default route is the "just send it to the gateway" intuition — written down.

- Em vez de ler teoria, perguntei ao kernel do meu Linux, ao vivo:

```
ip route get 192.168.0.50  →  ... dev wlp0s20f3            (sem via — vizinho, entrega direta)
ip route get 8.8.8.8       →  8.8.8.8 via 192.168.0.1 ...  (via — entrega pro gateway)
```

- **Insight consolidado:** toda linha da tabela é rota *conhecida*. A pergunta que cada linha responde não é "conheço?" — é "**entrego COMO?**": sem `via` = rota conectada, entrego direto; com `via` = entrego *através* do gateway (intermediário).

**Mecânica nova — casar prefixo (ler o SE da rota)**
- Cada linha é uma regra **SE → ENTÃO**. O número depois da barra diz quantos octetos do começo estão travados: `/8` = "começa com 10.", `/16` = "começa com 172.16.", `/24` = "começa com 192.168.0.", `/0` = qualquer coisa (a default).
- Pra testar: compara só os octetos travados. `8.8.8.8` vs `10.0.0.0/8` → 8 ≠ 10 → não casa.
- **Longest prefix match ganhou sentido literal:** mais octetos travados = mais específica = ganha. A default `/0` não trava nada — último recurso.
- **Nenhuma linha casa e não tem default?** Roteador não chuta: descarta e devolve **ICMP Destination Unreachable**. A default é a intuição "manda pro gateway" — por escrito.
