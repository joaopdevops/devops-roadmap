**Learned hexadecimal from scratch**
I had been reading "hex" everywhere without actually knowing what it was, so I stopped and learned it properly.

- It's base 16: sixteen symbols instead of ten. After 9 come A, B, C, D, E, F, where `A` is 10 and `F` is 15.
- It exists because binary is unreadable for humans. A MAC address is **48 binary digits**; in hex it's 12. Same number, four times shorter.
- The key rule: **1 hex digit = exactly 4 binary digits**, because 2⁴ = 16. So converting is mechanical — split the binary into groups of 4 and translate each group.
- Worked example: `10101111` → `1010` is 10 → `A`, `1111` is 15 → `F`, so the answer is **`AF`**.
- Realization: the `1A:2B:4D` I've always seen inside MAC addresses was hexadecimal the whole time. I'd been using it for months without knowing the name.

This one matters more than it looks: MAC addresses (Module 7) and all of IPv6 (Module 12) are written in hex. Without it, both turn into alphabet soup.
