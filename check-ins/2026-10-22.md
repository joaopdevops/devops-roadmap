## 🇬🇧 English

**HCI fundamentals, from zero — the four layers of a Nutanix cluster**

Objective 1.1 (cluster IP planning) felt too advanced because the fundamentals underneath it had never been closed. Went back and rebuilt them first.

| Layer | Concept | Key fact |
|---|---|---|
| Architecture | **HCI** (Hyperconverged Infrastructure) | compute + storage in the **same node**; software pools the disks — no separate SAN |
| Storage control | **CVM** (Controller VM) | **one per node**, owns that node's disks; together the CVMs form one storage pool |
| Virtualization | **AHV** (Acropolis Hypervisor) | Nutanix's own hypervisor, runs on bare metal and hosts every VM — including the CVM (ESXi and Hyper-V also supported) |
| Management | **Prism Element** vs **Prism Central** | PE: built in, runs on the CVMs, manages **one** cluster · PC: separate VM to deploy, manages **many** |

```
┌──────────────────────────────────┐
│  CVM   │  user VMs               │
├──────────────────────────────────┤
│  AHV (hypervisor)                │
├──────────────────────────────────┤
│  Hardware: CPU, RAM, disks       │
└──────────────────────────────────┘
```

Check questions: 4 nodes → **4 CVMs** ✅ · 1 CVM + 10 user VMs → AHV runs **11 VMs** ✅ · 5 clusters on one screen → **Prism Central**, separate deploy ✅.
Mistake caught live: "every VM has its own CVM" ❌ → **one CVM per node**, and the CVM *is* one of the VMs.

**Why it matters for DevOps:** the same stack (hardware → hypervisor → VMs → management plane) is what cloud providers abstract away; knowing each layer is what makes troubleshooting possible when the abstraction leaks.

## 🇧🇷 Português

**Fundamentos de HCI, do zero — as quatro camadas de um cluster Nutanix**

O Objetivo 1.1 (plano de IPs) parecia avançado porque a base embaixo dele nunca tinha sido fechada. Voltei e reconstruí os fundamentos primeiro.

| Camada | Conceito | Fato-chave |
|---|---|---|
| Arquitetura | **HCI** | processamento + armazenamento no **mesmo node**; software junta os discos, sem SAN separada |

| Gerência | **Prism Element** × **Prism Central** | PE: já vem, roda nas CVMs, 1 cluster · PC: VM à parte, vários clusters |

Erro corrigido ao vivo: "cada VM tem uma CVM" ❌ → **uma CVM por node**, e a CVM é uma das VMs.
