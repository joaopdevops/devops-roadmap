## 🇬🇧 English

**Consolidation day — routing table deep-read**
- Full read of the new **Routing Table (route decision)** concept note + its 10 production flashcards.
- Key ideas reinforced before tomorrow's lab:
  - Every route line is an **IF → THEN** rule; the prefix length says how many leading octets are locked (`/8` = "starts with 10.", `/0` = anything).
  - **Longest prefix match:** the most specific matching line wins; the default `/0` is the last resort.
  - `via` = deliver **through** the gateway (middleman); no `via` = connected route, direct delivery. Every line is a *known* route.
  - No matching line and no default → the router drops the packet and returns **ICMP Destination Unreachable**. Routers never guess.
