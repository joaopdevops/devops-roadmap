**Opening drill — /26** ❌ and it's the honest kind of failure
Asked for `192.168.10.100/26`. I answered mask `255.255.255.64`, 64 addresses, 62 usable. The host count was right. The mask was not — it's **255.255.255.192**.

What went wrong is worth writing down, because both numbers are real and I grabbed the wrong one:

- The **mask** comes from the bits that are on. `/26` is two bits into the last octet: `128 + 64 = 192`.
- The **block size** comes from `256 − 192 = 64`. It's how far apart the subnets sit: `.0`, `.64`, `.128`, `.192`.

So `64` does belong to this problem — as the block size, never as the mask. And since `.100` lives in the block that *starts* at `.64`, the number shows up twice without ever being the answer to the mask.

Full answer: network `192.168.10.64`, broadcast `192.168.10.127`, usable `.65` to `.126`.

**The part that actually stings:** my log from 2026-08-02 has this exact same `/26` answered 3/3, with me writing `255.255.255.(256−64) = 192` in the right order and noting the notation slip was healing. Thirty-five days without the drill and a skill I had demonstrably closed came back open. That reframes the daily drill for me: it isn't revision, it's the only thing holding that calculation in place.

**Environment hardening — a real finding on my own machine**
My home directory is itself a git repository (a Terraform + GitHub Actions project that was initialized at `~`). Its `.gitignore` covered `*.pem` and `credentials`, so I assumed it was safe. It wasn't: an SSH private key has **no file extension**, so `.ssh/id_ed25519` matched none of those rules. A careless `git add .` at `~` would have staged it.

Fix: inverted the logic from blocklist to **deny-all plus allowlist** — ignore everything at the repository root, then explicitly re-include only the project directories. Then audited the entire commit history to confirm nothing had ever leaked. It hadn't.

The takeaway I want to keep: a blocklist protects you from the secrets you thought of. An allowlist protects you from the ones you didn't.
